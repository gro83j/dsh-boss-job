# Phase 0.5：入口分流（不是职业规划服务）

本项目的主职是**筛岗**：帮已经有方向的人，在多城市、多方向里快速拉出可投清单，省掉一个个翻岗位的时间。**它不负责职业规划，也不替用户决定做什么**。

原因很直接：AI 对具体行业、岗位、公司的判断，和真实就业市场之间有偏差；这个偏差没法靠低成本的信息收集消除。方向错了，筛得再快也是白费。

所以这一阶段的正确动作是：**分流 + 给建议**，不是给用户做一份「AI 职业规划」。

## 第一层：入口两问（必须最先问）

按顺序问，一次只问一个：

1. **你现在是学生吗？**（在校本科/研究生/应届已毕业，都算学生；已工作选「不是」）
2. **你已经有心仪的岗位了吗？**（能说出具体岗位名，比如「电商运营」「新媒体运营」；说不出来就是「没有」）

| 学生 | 有心仪岗位 | 走向 |
| --- | --- | --- |
| 是 | 是 | 直接进 Phase 1 偏好访谈 |
| 是 | 否 | 先说明定位，建议先做职业咨询/找学长学姐聊，再做可选的「信息整理」；不硬做规划 |
| 否 | 是 | 直接进 Phase 1（顺带问一句「为什么想转」，不展开） |
| 否 | 否 | 同上：先建议专业咨询，再做可选的「信息整理」 |

## 第二层：没有目标时怎么做（克制版）

**先说清边界**，再决定要不要继续：

> 这个项目擅长的是「你已经知道要投什么岗位，我帮你快速筛出匹配的 JD」。职业方向这件事，AI 的判断和真实市场有偏差，我不适合替你拍板。更稳的做法是先做一次付费职业咨询，或者找目标行业的在职前辈聊 1–2 小时，把方向定下来，再回来用这个工具筛岗。

然后给三个低成本选项，让用户自己选：

1. **先去咨询**（推荐）：学校就业中心、职业规划师、行业前辈、付费咨询都行；用户回来后直接进 Phase 1。
2. **只做信息整理（可选，30 分钟）**：不问「你适合什么」，只把用户已经说过的信息整理成一张表——做过什么、能迁移的能力、现实约束、能想到的 3 个方向。明确标注「这是你的自述整理，不是职业建议」，让用户带去问人。
3. **坚持现在就要一个方向**：可以给 2–3 个**待验证假设**，每个都写清「为什么可能适合 + 需要验证什么（问谁、查什么）+ 最坏情况」，并再次提醒这是假设，不是规划。

### 信息整理表（选项 2）

只问事实，不做判断，1–2 轮问完：

- 学校/专业/年级，或之前的工作与年限
- 真实做过的 2–3 件事（负责什么、结果如何）
- 自己做得比周围人快/好的事
- 现实约束：城市、经济、家庭、时间
- 绝对不想碰的工作方式

整理成 `~/.dsh-boss-job/direction-notes.md`：

1. 用户自述摘要（只引用原话，不加工）
2. 可迁移能力清单（事实，不评级）
3. 用户提到的方向 + 每个方向「待验证的问题」
4. 建议的验证动作（问谁、查什么、试什么）
5. 明确声明：本文档不是职业规划，方向需由用户与专业人士确认

### 待验证假设（选项 3，仅在用户坚持时）

给 2–3 个方向，每个写：

- 为什么可能匹配（引用用户事实）
- 入门门槛与起步薪资（能搜 BOSS 就搜，查不到写「未知」）
- **需要验证的假设**（例：「你以为运营是策划，实际前半年是上架和报表」）
- 最坏情况与退出成本

不写 30/90/180 天计划——那是职业规划师的活。

## 第三层：转回主流程

方向确认后（不管是咨询回来的，还是用户自己定的），把方向写进 Phase 1 的 `directions`，继续问城市、薪资、排斥项，然后进入搜索与筛选。

## 规则

- 一次只问 1–3 个问题，等回答再继续。
- 不评判用户的学校、专业、空窗期。
- **不假装能替代职业规划**：不输出「你最适合××」的结论，只给事实整理或待验证假设。
- 薪资、门槛尽量用 BOSS 实时数据；查不到写「未知」，不编。
- 用户说「算了直接找」，尊重选择，带着已有信息进 Phase 1。
- 方法论参考了 MIT 许可的 [career-coach](https://github.com/Jeff-Kazzee/career-coach)，文本为本项目自写。
